# Stack: Next.js con shadcn/ui, Magic UI y Canvas UI

Se necesitaba un stack para un portfolio personal con buen SEO y margen para crecer (blog, features futuras) sin migrar de framework más adelante. Se evaluaron Astro (más liviano, ideal para sitios mayormente estáticos) y HTML/CSS/JS plano, pero se eligió Next.js por su flexibilidad y ecosistema. Sobre esa base se combinan shadcn/ui (componentes accesibles), Magic UI (animaciones) y Canvas UI (efectos WebGL), usando este último con moderación en 1-2 puntos puntuales para no romper la estética minimalista en escala de grises.
