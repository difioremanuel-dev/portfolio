## Fuente de contenido para Proyectos

Se evaluaron como alternativas al archivo de datos TypeScript estructurado:

- **Archivos Markdown por proyecto** — más cómodo para escribir descripciones largas, pero innecesario mientras el contenido sea corto y lo edite el propio autor.
- **CMS headless** (ej. Sanity, Contentful) — útil si algún día alguien no-técnico necesita editar proyectos, o si la cantidad crece mucho. Overkill para el arranque.

Reconsiderar si: la cantidad de proyectos crece significativamente, las descripciones se vuelven largas (case studies), o se suma un blog.
